# توافق إضافات المستودعات — تصميم مستقل، إصدار تجريبي

هذه وثيقة الدفعة الأولى. توسعة التنفيذ اللاحقة موثقة في ANDROID_WORKER_DESIGN.md وENGINE_ARCHITECTURE_STUDY.md؛ STATUS.md يميز نتائج الدفعتين.

المطلوب من المالك: دراسة CloudStream ثم Aniyomi وMihon وبناء توافق أصلي دون نسخ تنفيذ المشاريع، مع منع تعديل التورنت والمشغل والترجمة. هذا عمل طويل المراحل؛ هذه الدفعة تنجز بوابة الحزم ونواة سياسات التنفيذ، ولا تعلن تشغيل إضافات cs3 بعد.

## حدود ثابتة

- الأساس المنشور stable-214 / f20723d168bd45b9524244171be41f97f6a5dbd3. فرع مستقل، دون main merge أو Stable publication.
- لا تعديل في محركات المصادر الحالية أو بياناتها أو المخازن أو المكتبات أو محدّث التطبيق.
- إضافات CloudStream ليست JSON فقط: ZIP يحتوي manifest.json وDEX، واعتماديات JVM/Android/NiceHttp/Kotlin وتوقيعات callbacks. صحة الأرشيف لا تثبت توافق ABI أو أمان الكود.
- لا نسخ لتنفيذ upstream، ولا API فارغة تدّعي دعم وظيفة. المراجع والأسماء العامة للتشغيل البيني أدلة، والاختبارات والتنفيذ مؤلفان لفانتارا.
- لا تنفيذ لحزم أطراف ثالثة أثناء البحث، ولا طلب لمواقع المصادر؛ تنزيل الفهرس والحزم من مستودعها فقط. تحذير AnimeRift يمنع فحوص مصدر خلفية في السياسة اللاحقة.

## الوحدات

1. Package Gate: تحليل محدود لأرشيف cs3 وDEX، تحقق SHA/CRC وحدود التوسع والمسارات والتكرار ونقطة الدخول وميزانية metadata مشتركة، وتقرير اعتماديات بدون تنفيذ. البصمة المحسوبة لا تُسمى توقيع ناشر.
2. Runtime Policy Core: ميزانية مشتركة لكل نطاق، عزل مفاتيح البيانات حسب الجلسة، احترام Retry-After وCloudflare، إلغاء مضبوط ومنع إعادة المحاولة الآلية. النقل HTTP مسؤول مستقل عن DNS/TLS وSSRF والتحويلات في كل قفزة؛ النواة وحدها ليست حماية SSRF كاملة.
3. Executor Boundary: family/platform/profile/capabilities صريحة. لا يدعم PWA ملفات DEX بمجرد تحليلها. تعزل مرحلة Android المستقبلية التنفيذ في isolatedProcess مع InMemoryDexClassLoader وبروكر IPC محدود. فصل process بنفس UID وحده ليس sandbox.
4. Contract Profiles: تسجيل التواقيع المتاحة فعليًا وربطها بإصدارات الاختبار. عند غياب API تُرفض القدرة بوضوح بدل crash أو نتائج فارغة موهومة.

## المراحل التالية

- تحقيق Android مستقِل يشغّل إضافة اختبار أصلية ثم حزمة CloudStream فعلية في العملية المقيدة، مع إثبات تسجيل MainAPI وإكمال catalogue/search/details/episodes/videoLinks.
- أي ABI shim يجب أن يقدم دلالات حقيقية؛ الواجهات غير المنفذة تُعرض غير مدعومة ولا تعود بنجاح مصطنع.
- ربط Aniyomi وMihon بالمحركات الحالية عبر حدود النواة، دون إعادة كتابة الاستخراج أو تغيير sourceId. اختبارات موت العملية والتحديث والتفضيلات.
- بعد إثبات التشغيل: واجهة Debug فقط ثم تقييم مستقل لـStable. فصل المدمج مؤجل حتى نجاح النقل والرجوع وإغلاق التطبيق وسط الكتابة.

## القبول لهذه الدفعة

اختبارات هجوم أرشيف وتلف DEX، تحليل حزم فعلية مع pinned hashes دون تشغيلها، اختبار معدلات وRetry-After وعزل مصدر/جلسة، وحارس يرفض تغيير أي ملف موجود مسبقًا خارج هذه الوحدات والوثائق واختبار CI المنفصل.

النقل يتلقى request محدود الحقول مع سياقهوية immutable منفصل. سياسةHTTP وحدها لا تمنع executor موثوقًا يعمل داخل العملية من الوصول لواجهاتالنظام؛ عزل الكود غير الموثوق مؤجل للعامل المقيد. حد جسم الطلب1MiB وميزانية metadata للحزمة8MiB تقديرية محافظة، لا تعني نجاح كل حزمة شرعية كبيرة.
