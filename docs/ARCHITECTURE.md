# معمارية VANTARA الحالية

> **النطاق:** خريطة تنفيذية مرتفعة المستوى للمستودع كما روجع في 25 أكتوبر 2026. ليست وعدًا بتطابق كل المنصات، ولا بديلًا عن الكود أو العقود التفصيلية.

## 1. المنتج وحدود النظام

VANTARA تجربة متكاملة للمانجا والأنمي والسينما، مع مكتبة وحسابات وأصدقاء ومتابعة جماعية. **دائرة المستخدم خاصة**؛ التطبيق ليس شبكة اجتماعية عامة ولا يتطلب أن يكون كل مستخدميه في مجموعة واحدة مشتركة.

نفصل أربعة محاور:

1. **العرض والتفاعل:** واجهة JavaScript/CSS المشتركة في `apps/web/`.
2. **مصادر المحتوى وفكّه:** محركات وإضافات خاصة بكل منصة أو بروتوكول.
3. **المشغّل والتخزين المؤقت:** Media3 على Android، وmpv على Windows، وآليات المتصفح على PWA.
4. **الهوية والمزامنة:** Cloudflare Worker وD1 ومكوّنات نطاق البيانات الأخرى وفق ملكيتها.

## 2. خريطة مسارات التنفيذ

```text
                           apps/web (واجهة JavaScript/CSS)
                                       │
                ┌──────────────────────┼─────────────────────┐
                │                      │                     │
      Android / Capacitor       Windows / Electron       المتصفح / PWA
      Kotlin/JNI bridges        preload + IPC            JS / Web APIs
      قارئ ومشغّل Media3       مشغّل mpv مرفق          تشغيل بحسب المتصفح
      libtorrent للتورنت        rqbit للتورنت            لا تورنت TCP/UDP أصلي
      إضافات Kotlin             إضافات وخدمات Desktop    تعريفات مصادر/جالب ويب
                │                      │                     │
                └──────────────────────┼─────────────────────┘
                                       │
                      services/sync-worker (Worker + D1)
                        هوية/حسابات/تقدم/بيانات اجتماعية
                                       │
                         الخدمات المساعدة عند الحاجة
                  web-fetcher / content API / translation
```

هذه الرسمة **علاقات منطقية** وليست سلسلة طلبات واحدة يمر بها كل محتوى. على Android مثلًا قد يجلب المحرك الأصلي المحتوى مباشرة من المصدر، ولا يمر الفيديو عبر Worker.

## 3. الواجهة والقدرات

- `apps/web/index.html` و`app.js` و`v35/`: عرض الشاشات والتفاعل.
- `apps/web/lib/`: هوية الأعمال، الكتالوج، البيانات، المزامنة، سياسة الشبكة والقدرات.
- `apps/web/addons/`: مدير إضافات وعقود مصادر وسيرفرات وترجمات وواجهات ربط المنصات.
- `apps/web/lib/release.js` و`capabilities.js`: معرفة `apk` و`pwa` و`desktop` وقائمة الميزات المعروضة.
- `apps/web/pwa/`: حدود المتصفح والتثبيت والجلب والكاش؛ لا تُفترض فيها صلاحيات نظام التشغيل الأصلي.

**قاعدة:** القدرة المرئية في الواجهة لا تكفي لتوثيق أن الفيديو أو الترجمة أو الإضافة نجحت على جهاز حقيقي. تحقق من المصدر ثم المشغّل ثم الإطار المعروض.

## 4. المحركات حسب المنصة

### Android

- كود Android داخل `android/app/`، والجسور الأصلية تحت `android/app/src/main/kotlin/com/vantara/`.
- المحرك الأصلي للمانجا/الأنمي يستعمل موصلات المصادر الملائمة لأندرويد، ومنها إضافات Kotlin.
- الفيديو عبر **Media3**؛ تورنت APK عبر **FrostWire jlibtorrent / libtorrent**، مع قراءة القطع المتحقق منها ونافذة أولوية للتحميل عند التشغيل والقفز.
- وجود محرك أصلي لا يعني دعم كل ABI: الحزمة الحالية تستهدف معماريات معينة، ولا تُوعد أجهزة Android ذات 32 بت قبل بناء واختبار مكتبات متوافقة.

المراجع: [محرك الأنمي](ANIME_ENGINE.md)، [محرك تورنت أندرويد](addons/rebuild/native-torrent/ENGINE.md).

### Windows

- القشرة `apps/desktop/`: Electron وIPC وروابط موارد محلية.
- المحرك `apps/desktop/src/services.mjs` يشغّل **rqbit**؛ يقدّم نطاقات الفيديو إلى المشغّل عبر جسر HTTP محلي.
- الفيديو عبر **mpv** وعملية الفيديو المرفقة. توجد سياسة نافذة تنزيل وكاش إعادة تشغيل وتشخيص بدء التشغيل داخل `apps/desktop/src/`.
- اعتماد libtorrent بدل rqbit مجرد **اتجاه قابل للدراسة**؛ ليس المحرك الحالي ولا نتيجة مقارنة أداء مثبتة.
- مرجع النشر: [التحديثات الموحدة](UNIFIED_UPDATES.md)؛ [أدلة بدء التورنت](performance/windows-torrent-upstream-evidence-2026-10-19.md).

### Web / PWA

- الواجهة تعمل بالمتصفح مع service worker وIndexedDB ومحركات مصادر ويب.
- `services/web-fetcher/` يقدّم جلبًا مقيدًا للمضيفين والموارد المسموح بها؛ ليس محرك BitTorrent عام ولا خادم فيديو للتوزيع.
- قيود CORS والصيغ والترجمات وقدرات الترميز تعتمد على المتصفح؛ روابط التورنت الأصلية لا تعمل مباشرة في PWA التقليدي.
- مرجع: [PWA](PWA.md) و[عقود الإضافات](addons/CONTRACTS.md).

## 5. البيانات والخدمات

| المكوّن | دوره | ما لا ينبغي افتراضه |
| --- | --- | --- |
| `services/sync-worker/` | واجهات Cloudflare وحالة الحسابات والمزامنة/البيانات الاجتماعية في D1 | ليس خادم تنزيل تورنت أو بث لكل جهاز |
| `services/web-fetcher/` | جلب موارد لعميل الويب بحسب السياسة | لا يتجاوز حدود الأمان أو يمنح كل مصدر دعمًا تلقائيًا |
| `apps/api/` | خادم محتوى Fastify ضمن المكدس المستضاف ذاتيًا | ليس شرطًا لكل مصدر أصلي حديث |
| `packages/domain/` | عقود وملكية البيانات | لا تُبدَّل ملكيته بنسخة مخزنة مؤقتًا |
| `packages/db/` و`packages/uchiyomi/` | قواعد/عميل للمكدس المستضاف | لا يمثلان جميع مسارات قراءة المحتوى |
| `services/translation-worker/` | أعمال ترجمة وتحليل صور قيد التطوير والتجربة | لا تعني ترجمة آلية جاهزة بلا قيود لكل المنصات |

**مصدر الحقيقة لملكية البيانات:** [`packages/domain/src/ownership.ts`](../packages/domain/src/ownership.ts)، مع [المصفوفة المفسّرة](VANTARA_DATA_OWNERSHIP.md). المرايا/الكاش لا تتحول إلى مالك مستقل.

## 6. حدود الأمن والخصوصية

- إظهار كود الواجهة للعامة لا يمنح وصولًا إلى حسابات المجموعة؛ التحقق من الهوية والصلاحية يتم على الخدمات المعنية.
- تعامل مع رابط إضافة أو مزود وسائط على أنه مدخل غير موثوق: لا ترسل له رموز حسابات VANTARA أو أسرارًا خاصة.
- احفظ بيانات الدخول في مخازن الأسرار وبيئة النشر المخصصة، وليس `README` أو التذاكر أو سجلات التشخيص.
- لا تخلط بيانات مصادر خاصة أو محتوى مستخدم مع ملفات الإصدار أو أدلة الاختبار العامة.
- [عقود النقل](VANTARA_TRANSPORT.md) و[مصفوفة الأعطال](VANTARA_FAILURE_MATRIX.md) توثّقان مخاطر محددة؛ المراجعات الأمنية يجب أن تُختبر مقابل مسارات الكود الحالية.

## 7. كيف نحدد الإنجاز؟

الحد الأدنى: كود موجود ← اختبارات آلية حقيقية ← CI على المرجع المعني ← تجربة جهاز/منصة حقيقية ← إصدار Stable يحتوي التغيير. **هذه مراحل مختلفة** لا تُستبدل ببعضها. راجع [FEATURE_STATUS](FEATURE_STATUS.md) لتفريق الموجود عن المُثبت.
