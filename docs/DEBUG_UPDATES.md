# VANTARA Debug — قناة قابلة للتحديث دون حذف البيانات

## القناة الجديدة

- معرّف أندرويد الثابت: `com.vantara.app.debug`، مختلف عن Stable `com.vantara.app`.
- اسم التطبيق: `VANTARA اختبار`.
- الرقم يزداد مع تشغيل GitHub Actions: `0.0.<run number>`.
- فرع البناء المصرّح: `feat/addons-v7-native-manager-20261027` فقط.
- APK موقّع على نحو ثابت من أسرار GitHub (ولا يُحفظ أي مفتاح داخل المستودع)، ويُفحص SHA-256 وشهادة التوقيع قبل التوزيع.
- رابط التحميل الثابت: https://github.com/Meshal515/VANTARA/releases/download/debug-channel/VANTARA-debug.apk
- قناة بيان التحديث: https://github.com/Meshal515/VANTARA/releases/download/debug-channel/vantara-debug-update.json
- لا تستخدم هذه القناة بيان Stable ولا تغيّر `releases/latest`؛ تصدر كـ prerelease.

## كيف تختبر التحديث دون فقد المكتبة والمصادر؟

1. ثبّت أول APK موقّع من **Debug channel** مرة واحدة، وافتحه وثبّت مستودعًا ومصدرًا تجريبيًا.
2. عندما يصدر Debug جديد، افتح **الإعدادات ← النظام ← البحث عن تحديثات** أو حمّل `VANTARA-debug.apk` من الرابط الثابت.
3. وافق على تحديث أندرويد فوق التطبيق الحالي؛ لا تستخدم «إزالة التثبيت» ولا «مسح البيانات».
4. بعد إقلاع النسخة الجديدة، تأكد من وجود المستودع والإضافة وتقدم العمل كما كان.
5. عند الفشل، احتفظ بالنسخة الحالية وبالبيانات وأرسل سجلات الاختبار؛ لا تحذف التطبيق للعلاج.

## انتقال مهم من Debug القديم

النسخ القديمة المبنية في GitHub Actions كانت تستخدم مفتاح Debug مؤقتًا يختلف بين
الـ runners. **لا يمكن لأندرويد تثبيت APK موقّع بمفتاح آخر فوق تطبيق بنفس الاسم.
هذا قيد أمني لا يمكن تجاوزه**. عند أول الانتقال إلى قناة Debug الثابتة:

- **لا تحذف النسخة القديمة قبل استخراج نسخة احتياطية من بيانات مصادرها**.
- إذا كانت نسختك Debuggable، يمكن نسخ بياناتها محليًا بأداة `adb run-as`
  من كمبيوتر موثوق، بينما التطبيق القديم ما زال مثبتًا؛ بعدها يمكن الاستعادة
  بمسار محلي مع مراعاة اختلاف توقيع الجهاز/الموافقة على تسجيل الدخول.
- لا ترفع نسخة البيانات الاحتياطية إلى GitHub أو ترسلها لأي شخص؛ قد تتضمن جلسات حساب.
- النسخة الجديدة تعيش بجانب Stable ولا تنقل بيانات Stable تلقائيًا.

## ضمانات وفواصل أمنية

- يرفض البرنامج أي ملف APK ليس له اسم حزمة التطبيق المثبّت، أو شهادة التوقيع
  الرسمية نفسها، أو رقم إصدار أعلى، أو SHA-256 مطابق للبيان.
- يبقى تأكيد التثبيت بيد Android PackageInstaller، لا يتجاوز النظام.
- بناء محلي عادي `assembleDebug` ما زال يستخدم مفتاح Debug المحلي؛ **لا تستخدمه
  لتحديث قناة Debug الموقّعة**.
- لا توجد أي تهيئة إجبارية أو ترحيل لحذف المستودعات والمكتبات في هذا المسار.
- إصدار Debug الموقّع لا يحل محل اختبار APK الفعلي؛ يجب اختبار ترقية متتالية
  على جهاز أندرويد، مع فحص القائمة المثبتة قبل التحديث وبعده.
