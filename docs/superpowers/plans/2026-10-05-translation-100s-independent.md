# Independent 100-second translation candidate

Goal: 100 fresh accepted/saved pages in 100 seconds on S23 Ultra. This is an absolute engineering target, not a measured claim. User supplied design and execution authorization. Baseline `ec083d9` includes the working renderer/reader-priority repair. Work stays on `chatgpt/translation-100s-independent`; do not merge another AI's experiment.

1. Reproduce JS whole-page slot starvation and native network-reservation blocking. Add a bounded preparation lane to `createQueue`; route textless pages outside whole-page slots. Preserve deduplication, focus priority, dropped promises, errors and saved cache behavior. Test blocked dialogue versus later textless page.
2. Native detection has its own single owner and bounded metadata cache; pass the same detected page into analysis instead of rerunning RT-DETR. Add cheap component-based missing-text candidates confirmed by existing OCR before classifying textless. Cap candidates and never erase solely from geometry.
3. Keep rendering algorithm unchanged. Separate analysis/render owners and immutable analysis snapshots; serialize expensive inference at individual model-run boundaries, leaving independent lightweight detector and CPU render work available. Stop network reservation in the active plugin. Preserve ready-render priority within the render lane, cancellation and native resource ownership.
4. Activate ROI-only CTD/BubbleSeg in this independent experiment. Bound crop context and mapping; no production full-page fallback. Conditional BubbleSeg uses trusted local holder masks where available; otherwise model ROI. Verify accepted fast ownership, mask clipping and duplicate merging. Fixed-shape models still pay fixed tensor cost; count calls and crops honestly.
5. Strengthen known-region residual gate; failures cannot count as accepted. Keep safe whitening engines and LaMa crop admission; do not let Luna author pixel masks. Source-led lettering unchanged.
6. Bound/adapt network batches: true interactive page bypass, other reader pages batched; target up to 6 concurrent batches with 429 backoff and finite queue. Preserve same-work/chapter/mode identity, quota/cost accounting and failed-page isolation. Test backpressure and cooldown without duplicate paid requests.
7. Add 100-second benchmark threshold and scheduling metrics. Add native backend comparison evidence without blindly selecting NNAPI/OpenCV. Device runtime, quality recall and end-to-end timing stay UNVERIFIED until actual device/corpus.
8. Run web/worker/JVM/build/safety/font checks, independent review and publish exact tested tree to independent branch only. No merge, stable release or PWA deployment.

Research: ONNX Android provider availability is not proof of faster execution; fixed shapes and per-op fallback matter. Source URLs/evidence belong in the final report. Missing text candidates, residual checks and ROI masks require real-page visual acceptance before stable rollout.
