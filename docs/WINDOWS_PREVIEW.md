# VANTARA لويندوز — المعاينة الأولى

**الإصدار:** `0.1.0-preview.1` · **التاريخ:** 2026-10-14 بتوقيت الرياض.

هذه حزمة Windows x64 فعلية: مثبت NSIS ونسخة portable ZIP. تستخدم Electron
44.7.2 والواجهة الحالية ومدير إضافات Stremio، مع rqbit 9.0.1 وmpv مرفقين.
الرفيق والترجمة خارج نطاق نسخة ويندوز بتوجيه المالك. إصلاحات الغرف الموسعة
مؤجلة بعد هذه الحزمة؛ لا تعني هذه المعاينة اكتمالها.

## المعاينة الثانية: الواجهة الأصلية والمصادر والترجمة

الحزمة الجديدة `0.1.0-preview.2` تستعمل `index.html` و`app.js` وv35 الأصلية؛
الشاشة المبسطة ليست مدخل التطبيق. نقل الحسابات إلى Worker الأصلي يُعزل عن
نقل الإضافات؛ عولج CORS دون إلغاء webSecurity أو كشف Authorization للمصادر.
أقسام المانجا والأنمي والسينما تستعمل 27 تعريف مصدر بمحركاتها المشتركة؛
هذا ليس تشغيل ملفات DEX الخاصة بأندرويد على ويندوز ولا إثباتًا لتوفر كل موقع.

Torrentio مضمّن ببيانات المصدر المثبت على commit0d75331f، وCinemeta وOpenSubtitles
والمجمع العربي يُضافون بطلبات فعلية في الخلفية. حالة 403 تبقى ظاهرة ولا تُسمّى
جاهزية. روابط المستخدم والحذف والتعطيل محفوظة، والتحديث الخلفي يستعمل CAS
على cacheEpoch حتى لا يمحو إعدادًا أحدث. كاش المصادر IndexedDB منفصل عن
سجل الإضافات السابق؛ مرحلة ترحيل portable تسبق اختيار Electron لملفه الجديد.

ترجمات MPV تُجلب محليًا ≤2MiB مع تحقق DNS في كل تحويل CDN، وتُضاف دون إعادة
الفيديو؛ العربية لها أولوية ما لم يختر المستخدم مسارًا. الغرفة الأصلية مرتبطة
بأحداث المشغل وأوامر pause/seek/rate؛ تبقى جاهزة حتى يبدأ المضيف، ويظهر الأعضاء.
لم تُختبر جلسة حقيقية مع صديق من جهاز المالك.

portable يحفظ VANTARA-data بجوار exe (مثل E)، وسقف التورنت 64GiB مع فحص
مساحة الملف المحدد +64MiB قبل التنزيل. التحقق المحلي: 1291 اختبار واجهة،
54 safety، 32 خدمات تشمل rqbit وmpv الحقيقيين على Linux، و8 اختبارات قشرة.
فحص الحزمة الثانية على ويندوز يسبق نشرها عبر GitHub Actions. النتائج أدناه
تخص المعاينة الأولى حين لا يُذكر خلاف ذلك.

## الملفات

- `VANTARA-0.1.0-preview.1-Windows-x64-Setup.exe`، مثبت لحساب المستخدم دون Admin.
- `VANTARA-0.1.0-preview.1-Windows-x64.zip`، يفك ثم يشغّل `VANTARA.exe` من مجلده.
- `SHA256SUMS.txt` وبداخل الحزمة `BUILD-MANIFEST.json` والتراخيص ومصادر التبعيات.

محرك التورنت والمشغّل يعتمدان كذلك على Vulkan loader وMicrosoft CRT؛
أُرفقت DLLs x64 اللازمة app-local، وفُحصت بصماتها ومعمارية PE. رابط
الإعداد الخارجي `stremio://` يلتقط في نافذة إعداد معزولة ويعود إلى معاينة
تثبيت VANTARA، مع الحفاظ على مسار الرابط ومعاملاته دون عرض أسراره.

التخزين والإعدادات تحت أصل `vantara://app` ثابت. مدير الإضافات والواجهة
والمحرك يستعملون سجلًا واحدًا حتى لا تمحو إضافةٌ مثبتة من نافذة الإعداد
إضافةً أخرى محفوظة من المدير.

حزمة Windows مبنية من توزيعات أصلية لويندوز؛ تشغيل الواجهة والمحركين
الفعليين جرى على Linux. جُرّب المثبت المنشور على Windows Server 2022
وفُحصت كل الملفات وشُغّل mpv للتحقق من الإقلاع. **لم تُختبر واجهة التطبيق
أو named pipe أو فك الترميز على ويندوز، ولا Windows 10/11 أو جهاز المالك.** لا يحوّل نجاح الاختبار
المملوك خدمة Torrentio عامة أو عنوانًا بعينه إلى خدمة متحققة.

## حدود المعاينة

- حد الملف المختار 2 GiB. الحجم المجهول أو نقص المساحة يرفضان قبل التنزيل،
  مع احتياط 64 MiB؛ cache المتروك ينظف في الإقلاع التالي.
- رابط Torrentio المعدّ يُضيفه المستخدم؛ لا تُثبّت بيانات حساب أو رابط خاص تلقائيًا.
- DASH يرفض في واجهة المصادر؛ روابط HTTPS/HLS والتورنت هي مسارات هذه المعاينة.
- الترجمات المدمجة في الفيديو من المشغل؛ لا تدّعي المعاينة اكتمال ربط providers الترجمة الخارجية.
- مصادر Android/Kotlin الأصلية لا تعمل في هذه المنصة دون محرك خاص بها.
- الحزمة غير موقعة، وتحديثها يدوي بمثبت أحدث.

## إعادة البناء

المصدر `tools/build-windows.mjs` يتحقق من SHA-256 قبل فك التوزيعات.
يتطلب Python 3 و7-Zip وmakensis في بيئة البناء فقط، لا في جهاز المستخدم.
في البيئة ذات proxy يستخدم Node حديث مع `NODE_USE_ENV_PROXY=1`.
تدعم الأوامر خيارات `--output/--cache/--sevenzip/--makensis/--nsisdir`.
اختبارات خدمات Node الحقيقية تُفعّل بمساري `VANTARA_RQBIT_LINUX` و
`VANTARA_MPV_LINUX` مع DISPLAY عند استعمال mpv المرئي.

لتجاوز فشل عارض ملفات السحابة، تُسلّم الحزمة عبر إصدار GitHub تجريبي
`windows-v0.1.0-preview.1` من فرع ويندوز المستقل. لم يُدمج إلى `main`
ولم يُغيّر الإصدار المستقر أو يُنشر إصدار إنتاجي. يتضمن manifest بصمات البرامج المرفقة ومصادرها؛
مصدر التطبيق محفوظ في فرع المعاينة وتاغ الإصدار.

## بلاغ فشل كتابة mpv.exe

ورد من المالك خطأ NSIS `Extract: error writing to file mpv.exe` في أول تثبيت.
لم يتكرر مع نفس المثبت في اختبار ويندوز؛ هذه الرسالة تنتج عن فشل كتابة
ملف الوجهة أو cache المؤقت لفك الضغط، ولا تثبت وجود عطل في mpv أو سببًا
محددًا على جهاز المالك. المساحة المتاحة ومسار التثبيت لم يتحققا بعد.
الحزمة المحمولة متاحة للتجربة دون NSIS، مع فكها كاملة وتشغيل VANTARA.exe.

المعاينة الثانية اجتازت تثبيتًا وتشغيلًا فعليين على Windows Server 2022:
[دليل GitHub](https://github.com/Meshal515/VANTARA/actions/runs/38597162723).
حمّلت الواجهة 27 مصدرًا والإضافات العامة الأربع بطلبات ناجحة، وشُغّل فيديو
مؤلف وترجمة عربية عبر named pipe، مع pause/seek/rate وإغلاق المشغّل.
المعاينة الثالثة `0.1.0-preview.3` تحمل إصلاح المغادرة قبل أول إطار وتُفحص
بالسير نفسه قبل نشرها. لا تزال جلسة مشاهدة مع صديق وجهاز المالك غير مختبرتين.
