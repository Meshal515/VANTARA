# تعديلات الواجهة المحدودة — 2026-10-04

طلب المالك فحص الواجهة ثم فصل اختيار الترجمة عن تعديلها، وضبط Desktop للبنر واختيار السيرفر. ثم أضاف زر ⋮ وأفضل 5 للأنمي والسينما، ورفض الصورة الصغيرة المعزولة والفراغ الكبير في أول تجربة Desktop. لم يُغيّر منطق THE ROCK أو ترتيب السيرفرات أو الجودة أو NO AUTOPLAY لهذه التعديلات.

## قبل وبعد

| المشكلة | السبب | النتيجة |
|---|---|---|
| صورة الحلقة تخفي السيرفرات على Desktop | 16:9 بعرض الصفحة بلا حد | Desktop ≥1024px: صورة وسيرفرات جنبًا إلى جنب، عرض محتوى أقصى 1160px؛ نسبة الصورة الأصلية محفوظة. الجوال لم يتغير |
| بنر باتمان مقصوص من الأعلى | cover يكبر GIF بنسبة العرض العريض، ثم يقص الارتفاع | Desktop فقط object-position: center 25%؛ cover الأصلي والعرض وارتفاع 168px وAvatar والهوية كما كانت. الصورة تنتقل للأسفل داخل نفس القص دون تغيير مقياسها |
| اختيار الترجمات قد يغطي معظم الفيديو | ورقة عامة بحد 78% | ورقة الترجمة وحدها content-sized وحد 60%، scroll داخلي، فيديو مستمر |
| لا تحكم حي في Soft subtitles | لم توجد واجهة أو إدارة لتعديل cues | Panel منفصلة بثلاث Steppers؛ لا تتوفر دون track فعلية قابلة للتحكم |
| لا مدخل لأفضل 5 من الأنمي والسينما | ورقة أفضل 5 المشتركة كانت مرتبطة بصفحة المانجا | ⋮ في ترويسة العمل، ثم نفس اختيار الخانات الخمس وعمليات top.set الموجودة؛ لا API أو schema جديدة |

## صور فعلية من Chromium

استُخدمت مكونات VANTARA والـshell الحقيقيان، لا HTML مقلد. صورة/اسم/Avatar بروفايل @ngm من GET عام للقراءة، بلا جلسة حساب أو كلمة مرور أو كتابة للخادم. ثُبت إطار GIF الأصلي نفسه للمقارنة؛ بيانات المكتبة والنبذة الخاصة غير مسترجعة. هذه مقارنة مكونات محلية وليست دخولًا إلى حساب الإنتاج.

صور الحلقة وبيانات الإضافة/الفيديو في اختبار التخطيط fixtures مضبوطة؛ هي لا تثبت تشغيل تلك الحلقة من مصدر إنتاج. اختبارات المزود الحي والمصادر منفصلة في تقرير التنفيذ.

## السلوك وحدود runtime

- + يؤخر الترجمة، − يقدمها؛ 100ms، من −10 إلى +10 ثانية، استنادًا إلى التوقيت الأصلي دون تراكم خطأ.
- الحجم 75/100/125/150/175/200/250. 100% يحتفظ بأسلوب المتصفح؛ تغيير الحجم يطبق على soft cues فقط.
- الموضع 0–100% بخطوة 1؛ البداية 90% قرب موضع الترجمة المعتاد. لا تُحرّك cues الأصلية حتى يغير المستخدم الموضع.
- توقيت ملفات Source/Addon المستقلة يطبق Live. ترجمة HLS المُدارة من runtime لها حجم وموضع فقط؛ لا نعرض delay غير مدعوم.
- Off وتبديل Track/Server يسترجعان cues الأصلية ويصفّران التأخير. لا تفضيل Delay عامًا ينتقل إلى عمل آخر. الحجم/الموضع يبقيان في جلسة المشغل فقط، بلا تعديل إعدادات الحساب.
- Native Media3 يحتفظ بمسار اختيار الترجمة الحالي؛ هذه steppers تنفيذ PWA وليست ادعاء دعم Native Delay أو اختبار هاتف فعلي.

## تحقق المتصفح

موجب/سالب فعليان: cue تبدأ 2.00 ثانية → 2.10 → 1.90. أثناء ذلك سجل play/pause/load بقي **[]**، وcurrentTime تقدم من 0.804 إلى 4.040 ثانية، paused=false. الحجم 75/100/250، الموضع 0/50/100، إغلاق وفتح Panel، وغياب زر الترجمة عند غياب أي track/provider اختُبرت. قائمة 30 track: ارتفاع الورقة 506.39/844px (60%)، ارتفاع المحتوى 2176px والجزء القابل للتمرير 424px. لا page errors.

اختبار السينما حفظ `cinema:tt1254207` وposition=1 بنفس `top.set`؛ العملية اعتراض محلي فقط ولم يُكتب حساب الإنتاج. اختبار الأنمي حفظ `anime:123` وposition=1، لا مرجع مانجا مشتقًا من العنوان. [⋮ الأنمي](proofs/ui/anime-work-menu.png)، [خاناته](proofs/ui/anime-top-picker.png)، [picker الأنمي Desktop](proofs/ui/anime-picker-after-1366.png). اختبارات الوحدة 6 حالات للتحكم، مع 7 حالات جلسة الترجمة؛ المراجعة الكاملة بعد إصلاح حدود الإضافات مستقلة عن هذا التخطيط.

## الملفات

- `pwa/player/player.js`: مدخل التعديل وورقتان منفصلتان، عرض controls المدعومة فقط.
- `pwa/player/player.css`: modifiers محدودة لورقة الترجمة والـPanel، Steppers و::cue الحجم.
- `pwa/player/subtitle-adjustments.js` وtest: إدارة cues الأصلية والحية والحدود والتنظيف دون لمس الفيديو.
- `pwa/player/subtitles.js`: ربط track الحقيقية والتنظيف وأحداث HLS/ملفات الترجمة.
- `v35/anime.css`: تخطيط picker Desktop فقط، مشترك مع حلقات السينما.
- `v35/profile.css`: object-position Desktop فقط؛ أبعاد البنر وcover الأصليان محفوظان.
- `v35/anime.js` و`cinema.js` و`cinema.css`: زر ⋮ في الترويسة الحالية.
- `v35/shell.js`: إعادة استعمال أفضل 5 الموجودة، مع مراجع anime:/cinema: الصحيحة.
- `sw.js` و`lib/release.js`: precache ودقة بيان ما الجديد.

التحقق النهائي الكامل: **1510 اختبارًا /176 ملفًا**، **54** حراسة مستودع، TypeScript ناجح. تفاصيل إصلاح حدود الإضافات لا تُخلط بتعديلات التخطيط: [تقرير المراجعة](REVIEW-REPORT.md).
