# مرجع تصميم الإضافات المعتمد (v1.2.6)

`concept.js` هو كود التصور التفاعلي الذي اعتمده المالك (27 نوفمبر 2026) للجوال، وطلب على الكمبيوتر عمودًا واحدًا
مثل Nuvio بأحجام كبيرة وإجراءات ظاهرة. يعمل فوق لقطة من قشرة فانتارا الحقيقية، فهو مرجع سلوك وأبعاد وحركة لا كود إنتاج.

تعديلات المالك بعد v1.2.6 (تُطبَّق عند النقل إلى `apps/web/v35`):
- الإضافة المعطّلة تُرسم مبلورة ومعطّلة من أول إطار عند الرجوع (لا وميض ثم بلور).
- المفتاح المفعّل داكن، لا بلون الثيم.

## خطة النقل إلى فانتارا الحقيقي (27 نوفمبر، تصحيح المالك: «التصميم هو الـHTML بالضبط»)

الشاشة الحقيقية = `concept.js` نفسه (الهيكل والأحجام والحركة والأوراق)، بتعديلات المالك، مربوطًا بالبيانات الحقيقية:

| في الـHTML | المصدر الحقيقي |
|---|---|
| مزوّد Stremio وإضافاته | `addons.registry` (list/remove)، والإضافة برابط عبر مسار الاستيراد الحالي (`processInput`) |
| Mihon / CloudStream / Aniyomi: المثبتة | `repositories()` و`cloudstreamRepositories()` و`animeRepositories()` (`list().installed`) |
| المتاحة | `extensions(url)` لكل مستودع، والتثبيت `install(url, pkg)`، والحذف `uninstall(pkg)` |
| المستودعات وإضافة مستودع | `list().repos` و`add(url)` و`remove(url)`؛ ورقة «مستودع جديد» بالمعاينة كما في الـHTML |
| «تحديات الحماية» | `verification.subscribe/begin` (lib/source-verification.js) |
| شريط الأرقام و«حدّث الكل» | عدد المثبت وما عليه `update`، والتحديث بمسار التثبيت نفسه |
| 📌 المفضّلة والترتيب | ترتيب محلي لكل حساب (تفضيل عرض، لا بيانات حرجة) |
| المفتاح (تفعيل/تعطيل) | يظهر فقط حيث يدعمه المحرك (`enabled`)؛ لا مفتاح شكلي |

لا زر بلا وظيفة: ما ليس له نظام حقيقي يُبنى أو يُحذف من الواجهة، ولا يُزيَّف.
