# VANTARA — خطة إغلاق فروق ويندوز / الإضافات / المشاهدة المباشرة

> 2026-10-14. **فرع ويندوز فقط**، لا تعديل للـAPK المستقر دون طلب مستقل.
> مبدأ المشروع: عالج السبب والانتقال تلقائيًا، ولا تكتف باستبدال «حدث خطأ» بجملة مفهومة.
> لا يمكن ضمان تشغيل تورنت بلا مشاركين أو شبكة؛ التمييز بين الشروط الخارجية والعيوب مهم.

## P0: محرك ويندوز والمشغل
- [x] اختيار فيديو وحيد من حزمة تورنت متعددة الملفات تلقائيًا دون التخمين بين حلقتين.
- [x] إعادة محاولة أخطاء جلب metadata المؤقتة فقط؛ 400 و401 و403 لا يعاد إرسالها دون سبب.
- [x] إعداد cache أولي للمشغل؛ إعادة فتح محلية واحدة إذا لم يصل أول إطار خلال المهلة.
- [x] اختبارات توقف أول إطار وجلب metadata وإلغاء الجلسة.
- [ ] نقل **عرض الفيديو والتحكم الكامل** إلى واجهة VANTARA بدل نافذة mpv منفصلة: حل هندسي مثبت على Windows 10/11 مع ملفات MKV/H265 وحفظ تحكم الغرف، وليس مجرد نافذة HTML تتعطل مع بعض codecs.
- [ ] اختبار تورنت عامة متنوعة مسموحة، والملف نفسه عدة مرات، واختبار تغيّر المشاركين وقطع/عودة الشبكة والبحث عن المصدر البديل.
- [ ] كاش قطعة التورنت لاستكمال العرض عند إعادة التشغيل مع حد تخزين ومهلة صلاحية، دون الكتابة غير المحدودة أو كشف الملفات.
- [ ] التحقق من فحوص التورنت قبل عرض READY؛ المصدر الخارجي لا يعني أن المشاركين متاحون.

## P1: الترجمة والإضافات
- [x] مدير إضافات فانتارا يدعم معاينة رابط manifest، والتثبيت الصريح، والعودة من نافذة ضبط Stremio داخل فانتارا.
- [x] ربط ترجمة الأنمي بالهوية الدقيقة MAL/AniList → Kitsu عند توفرها، مع بقاء تشغيل الفيديو مستقلًا عن فشل المزود.
- [ ] اختبار Re:Zero الحقيقي: عمل/حلقة/مصدر، فحص نتائج موفّر ترجمة لكل لغة، جودة المطابقة والتقديم اليدوي.
- [ ] إعداد مصدر خارج نافذة فانتارا: لا يمكن الاستيلاء على بروتوكول stremio:// المسجل لتطبيق آخر تلقائيًا دون موافقة النظام. وفر رابط VANTARA رسميًا وآلية استيراد مباشرة دون تحويل إلى Stremio.
- [ ] واجهة داخل مشغل VANTARA لتبديل/تحميل ملف SRT/ASS/VTT، حجم/خط/موضع/توقيت وإظهار المصدر.
- [ ] عزل الإضافات غير السليمة ومنع تكرار التثبيت أو فقد بيانات إعدادات موجودة.

## P1: Together
- [x] إزاحة **المحتوى المحلي** للفيديو ±120 ثانية بخطوة 0.25 ثانية دون تغيير ساعة المضيف أو التأثير على الآخرين، وتصفر لكل حلقة جديدة.
- [ ] وصول الإزاحة لكل مستخدم إلى مشغل أندرويد/الويب بطريقة متكافئة، باختبار عبر أجهزة حقيقية؛ لا تغيّر APK الآن.
- [ ] اختبارات طرف لطرف: كمبيوتر + جوال + آيباد، إيقاف/تقديم، فقد اتصال وعودة، مصدران مختلفان، اختلافات intro.
- [ ] تحليل معدل تحديث التمرير في قارئ المانجا للمشاهد البعيد: إذا أرسل صاحب الصفحة 3 تحديثات/ثانية، العارض يستطيع **الاستيفاء البصري** بسلاسة، لكن لا يحق اختلاق مواضع دقيقة أو حمل كل صورة على الشبكة. افحص البث والتصيير قبل وصف السبب. لا تخلط معدل أحداث الشبكة مع FPS تصيير المتصفح.

## P2: آخر تحديثات المانجا
- [ ] قياس شمول التحديثات عبر مصادرها والوقت المنشور الفعلي، بدل افتراض أن جميع المصادر تدعم آخر دقيقة.
- [ ] تفادي إعادة القارئ لأعلى عند تحميل المزيد أو تحديث القائمة وإبقاء حالة lazy-load للأغلفة.
- [ ] إزالة تكرار الأعمال بناء على هوية متعددة المصادر/نسخ مترجمة بتمييز واعٍ لا دمج بالعناوين فقط.
- [ ] استلام صور الواجهة لتحديد مسار العطل قبل أي تغيير.

## بوابة الشحن
- نجاح اختبارات الوحدات والتكامل وWindows-native-smoke لا يساوي إثبات المشاهدة الحقيقية مع الأصدقاء.
- الإصدار التجريبي غير موقع، ولا يندمج في stable إلا بقرار منفصل.
