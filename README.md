# VANTARA

مكتبة وقارئ خاص للمانجا والمانهوا والمانها لثلاثة مستخدمين، مبني كطبقة فوق
[Uchiyomi](https://github.com/AngeloSha/uchiyomi) — لا من الصفر.

**الحالة:** مرحلة Spike. لا يوجد كود تطبيق بعد، وهذا مقصود.

## المعمارية المثبتة

```
VANTARA                     ← Presence · Social · Profiles · الترجمة العربية
  ↓  REST + API token
Uchiyomi                    ← المكتبة · المستخدمون · التقدم · القارئ · التنزيل
  ↓  SUWAYOMI_URL
Suwayomi (مدمج upstream)    ← البحث · الفصول · الصفحات
  ↓
Mihon / Keiyoushi extensions
  ↕  FLARESOLVERR_URL
FlareSolverr                ← إلزامي، لا اختياري
```

VANTARA **لا يكتب تقدمًا** ولا يشغّل نسخة Suwayomi خاصة. انظر D-01 و D-02.

## الخلاصة في ثلاثة أرقام

- **1,392** إضافة في كتالوج Keiyoushi، منها **38 عربية**.
- **25** سقف المصادر المفعّلة افتراضيًا (`SUWAYOMI_MAX_SOURCES`).
- **2 من 5** مصادر عربية مختارة بعناية عملت من أول محاولة بشكل كامل.
