# VANTARA

**منصة ترفيهية شخصية تجمع المحتوى والأصدقاء في تجربة واحدة.**

VANTARA تطبيق للأنمي والأفلام والمسلسلات والمانجا والمانهوا والمانها. يجمع اكتشاف الأعمال ومتابعتها وقراءتها ومشاهدتها، مع مكتبة شخصية ومزامنة للتقدم ومساحات خاصة للتفاعل والمشاهدة أو القراءة مع الأصدقاء.

**التميّز الأساسي:** فانتارا ليس شبكة اجتماعية عامة ولا مكتبة محتوى ثابتة. يبني المستخدم تجربته باختيار مصادره وإضافاته، بينما يتولى التطبيق عرض المحتوى وتشغيله وتنظيمه وربط الأصدقاء.

> **حالة المشروع — أكتوبر 2026:** المنتج قيد التطوير والتجربة الخاصة، ويضم تطبيقات لأندرويد وويندوز والويب. هناك ميزات قائمة بالكود وأخرى تحتاج تحققًا عمليًا أو استكمالًا. **التسجيل العام غير متاح حاليًا**؛ وجود المستودع أو حزم التثبيت لا يمنح حق الوصول إلى حسابات التجربة. الهدف إتاحته مستقبلًا مجانًا للجميع، بعد استكمال متطلبات الأمان والتشغيل والتوسّع، دون موعد إطلاق معلن.

## تجربة واحدة، ثلاثة أقسام

| القسم | ما يقدمه |
| --- | --- |
| **الأنمي** | اكتشاف الأعمال والحلقات، اختيار مصادر المشاهدة، مشغّل فيديو، مكتبة وتقدم. |
| **السينما** | أفلام ومسلسلات ومواسم وحلقات، خيارات تشغيل متعددة، مكتبة ومتابعة. |
| **المانجا** | مانجا ومانهوا ومانها، فصول وصفحات وقارئ، تقدم ومصادر قراءة متعددة. |

تتكامل الأقسام مع الحسابات والملفات الشخصية والمجلس والتوصيات والأنشطة، دون جعل التجربة مجتمعًا عامًا مفتوحًا. بعض سيناريوهات القراءة والمشاهدة الجماعية لا تزال بحاجة إلى تحقق شامل بين أجهزة حقيقية.

## الإضافات في قلب التجربة

**الرؤية النهائية: محتوى قابل للتوسعة بدل مصادر مفروضة.**

- **الأنمي والسينما:** تتجه البنية إلى جعل الإضافات الطريقة الرئيسية لتوفير الكتالوج والحلقات ومسارات التشغيل والترجمات. التورنت مسار مهم عندما توفره الإضافة وتدعمه المنصة، مع الاحتفاظ ببدائل البث الأخرى.
- **المانجا:** المحركات والمصادر المدمجة تعمل حاليًا ولا تُزال قبل وجود بدائل مختبرة. الهدف تعزيز تثبيت مصادر القراءة وإدارتها وتحديثها عبر الإضافات دون الحاجة إلى إصدار التطبيق من جديد عند إضافة كل مصدر.
- **مدير الإضافات:** اكتشاف الإضافات ومعاينتها وتثبيتها وإدارتها بحسب قدرات النظام والمنصة، مع عزل بيانات الحساب واحترام حدود الأمان.
- **التثبيت المستقبلي:** تجربة بداية نظيفة بلا مكتبة محتوى أو مصادر خارجية مفروضة ولا حسابات شخصية مسبقة؛ المستخدم يختار ما يريد إضافته.

**هذه استراتيجية تطوير، وليست ادعاء بأن كل المصادر المدمجة أزيلت اليوم.** تختلف قدرات الإضافات بين Android وWindows وPWA.

## المنصات الموجودة بالكود

| المنصة | التقنية | تشغيل الوسائط |
| --- | --- | --- |
| **Android** | Capacitor وKotlin | Media3، ومحرك libtorrent الأصلي في الأجهزة المدعومة. |
| **Windows x64** | Electron | مشغّل mpv ومحرك rqbit للتورنت. |
| **Web / PWA** | JavaScript وواجهات المتصفح | حسب دعم المتصفح والمصدر؛ التورنت التقليدي TCP/UDP ليس متاحًا مباشرة في المتصفح. |

الواجهة الأساسية مشتركة، لكن المحركات الأصلية والإضافات وقدرات التشغيل تختلف بحسب النظام. **خطة الإتاحة العامة الحالية تركز على Android وWindows؛ نسخة PWA موجودة برمجيًا لكنها ليست خدمة عامة مستهدفة الآن.** دعم iPhone يتطلب عميل iOS أصليًا أو قرارًا لاحقًا بإتاحة PWA، ولا يُعد متاحًا حاليًا.

## المعمارية باختصار

```text
                  VANTARA — واجهة وتجربة مشتركة
                     apps/web  (JavaScript/CSS)
                                 │
                ┌────────────────┼────────────────┐
                │                │                │
             Android          Windows          Web/PWA
          Kotlin/Media3      Electron/mpv       Web APIs
           libtorrent           rqbit           مصادر ويب
                │                │                │
                └────────────────┼────────────────┘
                                 │
                     المزامنة والحسابات
                  Cloudflare Worker + D1
```

تتم معالجة الوسائط والمصادر وفق قدرات كل منصة؛ لا يعني هذا الرسم أن ملفات الفيديو أو التورنت تمر عبر Cloudflare. للمكونات وحدودها: [المعمارية](docs/ARCHITECTURE.md).

## الإتاحة المجانية مستقبلًا

هدف المشروع إتاحة تجربة VANTARA الأساسية **مجانًا لجميع المستخدمين**، بحيث يستطيع كل شخص إنشاء مكتبته واختيار إضافاته والاستمتاع بالمحتوى بمفرده أو مع أصدقائه.

يعتمد التصميم المستهدف على تشغيل الوسائط والتورنت على **جهاز المستخدم** بدل تحميل خوادم VANTARA تكلفة بث الأفلام والمسلسلات، وعلى إبقاء خدمات الحسابات والمزامنة خفيفة وقابلة للتوسع. يمكن تمويل تشغيل الخدمات عند الحاجة بالتبرعات أو الدعم الاختياري، دون جعل الوصول الأساسي للتطبيق اشتراكًا إلزاميًا.

**النموذج المعتمد مستقبلًا: الاستضافة الذاتية لكل صاحب مساحة.** ينشر صاحب المساحة Cloudflare Worker وقاعدة D1 وغرفه من حساب Cloudflare الخاص به، ويدعو أصدقاءه، ويتحمل هو حدود الخطة المجانية أو رسوم الترقية إن اختارها. لا يُطلب من مطور VANTARA دفع تكاليف خوادم حسابات المستخدمين، ولا يُتوقع من كل صديق فتح حساب Cloudflare. تحديثات التطبيق تصدر مركزيًا، وتحديثات خدمة كل مساحة تُنشر بتفويض من صاحبها.

هذا **هدف منتج لم يُنفَّذ بعد بالكامل، وليس إعلان فتح التسجيل أو ضمانًا بأن كلفة المشروع ككل ستكون صفرًا**. ولا يوفر VANTARA تراخيص أو اشتراكات مدفوعة في خدمات محتوى خارجية مجانًا.

[تفاصيل الاستضافة المجانية والتحديثات الموزعة](docs/SELF_HOSTING_AND_UPDATES.md).

## للمطورين

المستودع متعدد الحزم ويحتاج **Node.js 22+** و**pnpm 10.33.0** لمسار JavaScript/TypeScript الأساسي. بناء Android أو Windows له متطلبات إضافية.

```bash
corepack enable
pnpm install
pnpm test:web
pnpm test:safety
pnpm typecheck
pnpm lint
```

## الأمان والمساهمة

التطبيق التجريبي يحمي الوصول إلى حساباته وخدماته بصلاحيات الخادم، ولا يكفي إخفاء زر التسجيل لتحقيق ذلك. تجنب نشر الرموز السرية وبيانات المستخدمين وروابطهم الخاصة في البلاغات أو سجلات التشخيص.

**كون المستودع عامًا لا يجعله مفتوح المصدر قانونيًا تلقائيًا.** أي إتاحة للكود بشروط إعادة استخدام واضحة تتطلب ملف ترخيص وقرارًا مستقلًا. يسعدنا استقبال البلاغات التقنية، لكن لا يوجد التزام بدعم جميع المصادر والأجهزة في المرحلة الحالية.
