# VANTARA

مكتبة وقارئ خاص للمانجا والمانهوا والمانها، لثلاثة مستخدمين: مشعل ومنصور ودحمي.
واجهة عربية بالكامل، تعمل على الويب وداخل تطبيق أندرويد.

**الحالة:** التطبيق مبنيٌّ ويعمل. الواجهة والمزامنة ومحرّك الإضافات وAPK كلها
قائمة ومختبَرة وتُنشر آليًّا. وما لم يكتمل بعد مذكورٌ صراحةً في
[§ ما لم يكتمل](#ما-لم-يكتمل) — لا يُوصف شيء بأنه جاهز قبل أن يُثبَت.

---

## ما هو VANTARA بالضبط

أربع قطع تعمل معًا، ولكلٍّ منها دورٌ منفصل وسببٌ لوجودها منفصلًا:

```
                    ┌─────────────────────────────────┐
                    │  الواجهة  apps/web              │
                    │  JS عادي بلا إطار ولا مُجمِّع     │
                    └───┬──────────┬──────────┬───────┘
                        │          │          │
        ┌───────────────┘          │          └───────────────┐
        ▼                          ▼                          ▼
┌───────────────────┐  ┌────────────────────┐  ┌─────────────────────────┐
│ المزامنة          │  │ خادم المحتوى       │  │ محرّك الإضافات           │
│ services/         │  │ apps/api           │  │ android/app             │
│   sync-worker     │  │                    │  │                         │
│                   │  │ Fastify + Postgres │  │ إضافات Keiyoushi        │
│ Cloudflare Worker │  │ فوق Uchiyomi       │  │ تعمل داخل الجهاز        │
│ + D1              │  │                    │  │ (Kotlin + DexClassLoader)│
│                   │  │ المكتبة · التنزيل  │  │                         │
│ الحسابات·الأصدقاء │  │                    │  │ المصادر · الفصول        │
│ الحضور·التقدّم     │  │ يعمل حين يكون     │  │ الصفحات — **بلا خادم**   │
│ الإحصائيات        │  │ جهاز البيت مفتوحًا │  │                         │
│                   │  │                    │  │                         │
│ يعمل دائمًا، مجانًا│  │ عبر Cloudflare     │  │ داخل الـAPK وحده        │
│                   │  │ Tunnel             │  │                         │
└───────────────────┘  └────────────────────┘  └─────────────────────────┘
```

### لماذا هذا الفصل

**المزامنة منفصلة عن المحتوى** لأن جهاز البيت ينام. الأصدقاء والحضور والتقدّم
تبقى حيّة على Cloudflare بلا كلفة، فلا يبدو التطبيق معطوبًا لأن حاسوبًا أُطفئ.

**محرّك الإضافات داخل الجهاز** لأن قراءة المصدر لا تحتاج خادمًا أصلًا. إضافات
Keiyoushi كود JVM مُصرَّف، وأندرويد يشغّله. وهذا يعني أن القراءة تعمل **بلا
حساب وبلا خادم وبلا إعداد** — وهو أكثر ما يُستعمل التطبيق لأجله. التفصيل في
[`CAPACITOR_EXTENSION_BRIDGE.md`](CAPACITOR_EXTENSION_BRIDGE.md).

> هذا **نقضٌ** لما قرّرته [`docs/VANTARA_EXTENSIONS.md`](docs/VANTARA_EXTENSIONS.md)
> سابقًا (§1: «تشغيل الإضافات داخل الـAPK ❌ مرفوض»). الـspike أثبت العكس على
> جهاز حقيقي، والقرار انقلب بالدليل. الوثيقة باقية لأن تحليلها لبقية المسائل
> سليم، وصدر تصحيحها مكتوبٌ فيها.

**المصادر تُقرأ ككتالوج واحد.** القارئ لا يختار مصدرًا: البحث يسأل الخمسة معًا،
والعمل الذي تحمله ثلاثة يظهر بطاقةً واحدة، وفصولُه اتحادُ ما عندها. فعملٌ يقف
عند الفصل ١٢٠٠ في مصدر ويبلغ ١٣٠٠ في آخر يُقرأ ١٣٠٠.

## خريطة المستودع

| المسار | ما فيه |
|---|---|
| `apps/web/` | الواجهة. JS عادي، بلا إطار ولا خطوة بناء. تُنشر على Pages وتُحزَم في الـAPK |
| `apps/web/lib/` | المنطق الخالص: `catalog.js` (دمج المصادر) · `sync.js` · `queue.js` (طابور عدم الاتصال) · `netpolicy.js` · `content-api.js` |
| `apps/web/screens/` | الشاشات: `sources.js` (الكتالوج والعمل والقراءة) · `accounts.js` |
| `apps/api/` | خادم المحتوى. Fastify + Postgres، طبقة فوق Uchiyomi |
| `services/sync-worker/` | Cloudflare Worker + D1: الحسابات والأصدقاء والحضور والتقدّم |
| `services/translation-worker/` | الترجمة العربية. Python + Pillow/RAQM للرسم العربي |
| `packages/domain/` | العقود والقواعد المشتركة (zod). **مصدر الحقيقة** لمصفوفة الملكية |
| `packages/db/` | Postgres والهجرات |
| `packages/uchiyomi/` | عميل Uchiyomi REST |
| `android/` | قشرة Capacitor **ومحرّك الإضافات الأصلي** (Kotlin) |
| `spike/` | الـspike الذي أثبت المحرّك، ومشروع تشخيص مستقل يبقى للرجوع |
| `infra/` | Docker Compose ونسخ Postgres الاحتياطية |
| `tools/repository-safety.test.mjs` | فحوص سلامة تمنع الوثائق والكود من التباعد بصمت |

## التشغيل والاختبار

```bash
pnpm install

pnpm test          # كل الاختبارات
pnpm test:web      # اختبارات الواجهة وحدها (سريعة، بلا قاعدة بيانات)
pnpm test:safety   # فحوص سلامة المستودع
pnpm typecheck
pnpm lint

pnpm dev           # خادم المحتوى محليًّا
pnpm migrate       # هجرات Postgres
```

الواجهة بلا خطوة بناء: `apps/web` يُخدَم كما هو. وبناء الـAPK:

```bash
npx cap sync android
cd android && ./gradlew :app:assembleDebug
```

مكدّس المحتوى المستضاف ذاتيًّا (Uchiyomi + Suwayomi + FlareSolverr + Postgres)
في [`docs/DEPLOY.md`](docs/DEPLOY.md).

## النشر — ماذا يُنشر ومتى

| السير | ماذا يفعل | متى |
|---|---|---|
| `ci.yml` | فحوص السلامة، الاختبارات، التصريف، فحص الأنواع | كل دفعة |
| `android-debug.yml` | APK غير موقّع، وهو الذي يصرّف Kotlin | كل دفعة، أي فرع |
| `cloudflare-pages.yml` | نشر الواجهة على Pages | بعد نجاح CI على `main` |
| `sync-worker.yml` | نشر الـWorker وهجرات D1 وأسراره | بعد نجاح CI على `main` |
| `android-release.yml` | APK موقّع | عند وسم إصدار |

النشر الإنتاجي **لا يُشغَّل من فرع**: يفتح بـ`workflow_run` بعد نجاح CI على
`main` وحده، فكود فرعٍ تجريبي لا يستطيع تعديل بوابة النشر ثم تشغيلها بنفسه،
ولا تُمسّ D1 قبل أن تنجح الاختبارات.

## ما لم يكتمل

- **الترجمة العربية** (`services/translation-worker`): الرسم العربي محسوم
  بالبكسل (Pillow/RAQM)، والكشف والـOCR والـinpainting لم يُقاسا على عتاد
  حقيقي. الخطوات في [`spike/SPIKE.md`](spike/SPIKE.md).
- **إدارة دورة حياة الإضافات**: بيان المصادر الخمسة مثبَّت في
  `android/app/.../Sources.kt` ببصماته. لا تحديث تلقائي ولا رجوع آليّ بعد.
- **مطابقة العناوين عبر الأبجديتين**: `Solo Leveling` و«سولو ليفلنج» يبقيان
  عملين. النقل بالتخمين يدمج أعمالًا مختلفة، وخطؤه يعرض فصول عملٍ آخر.

## القواعد الحاكمة

> **لا يُوصف مصدر بأنه مدعوم قبل أن ينجح:** البحث، وقائمة الفصول، وصفحات فصل
> قديم، وصفحات فصل حديث، وفكّ ترميز الصور فعليًا.

> **لا مالك ثانٍ لأي بيان.** مصفوفة الملكية في `packages/domain/src/ownership.ts`،
> ويفشل البناء إذا خالفتها الوثيقة.

> **لا ✅ بلا دليل.** لا تُعتبر مشكلة مُصلَحة لأن الكود تغيّر: اختبارٌ يثبتها،
> ثم إصلاح، ثم CI أخضر، ثم تجربة المسار الحقيقي.
