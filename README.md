# VANTARA

**مساحة ترفيهية خاصة تجمعك بأصحابك حول الأنمي والمانجا والأفلام والمسلسلات.**

VANTARA تطبيق متعدد المنصات يجمع اكتشاف الأعمال ومتابعتها وقراءتها ومشاهدتها، مع المكتبة والتقدّم والحسابات والأصدقاء في تجربة واحدة. الفكرة ليست إنشاء شبكة اجتماعية عامة؛ بل تمكين كل مستخدم من الاستمتاع بالمحتوى والتفاعل مع دائرته الخاصة.

> **وضع المشروع:** تطوير وتجربة خاصة. وجود المستودع أو ملفات التثبيت على GitHub لا يعني أن خدمة الحسابات مفتوحة للجميع. الهدف مستقبلًا إتاحة التطبيق على نطاق أوسع بعد تحسين جاهزيته. لم يُعلن موعد للإطلاق العام.

## ماذا يقدّم؟

| القسم | التجربة |
| --- | --- |
| **المانجا** | المانجا والمانهوا والمانها؛ اكتشاف الأعمال والبحث، الفصول، قارئ الصور، المكتبة والتقدّم. |
| **الأنمي** | اكتشاف الأنمي والحلقات والمصادر، اختيار مسارات المشاهدة والمشغّل المناسب للمنصة. |
| **السينما** | الأفلام والمسلسلات، صفحات الأعمال والحلقات/المواسم والمشاهدة. |
| **الأصدقاء** | الحسابات والملفات الشخصية، المجلس، الحضور، النشاط، التوصيات والتفاعل داخل المجموعة الخاصة. |
| **معًا** | واجهات ونظام للمشاهدة أو القراءة المتزامنة بالدعوات؛ بعض السيناريوهات بين أجهزة حقيقية ما زالت بحاجة إلى تحقق شامل. |
| **الإضافات** | مصادر وإضافات بقدرات تختلف حسب المنصة، بما فيها تكاملات متوافقة مع Stremio؛ ليست كل إضافة أو قدرة مدعومة على كل جهاز. |

التطبيق يوفّر أدوات متابعة وحفظ وتحديث للمحتوى بحسب المصادر المتاحة. **لا نعد بتوفّر عمل أو جودة أو ترجمة بعينها**؛ لأن النتيجة تعتمد على المصدر والمنصة والحالة الفعلية للشبكة.

## المنصات

| المنصة | التطبيق | تشغيل الوسائط والتورنت |
| --- | --- | --- |
| **Android** | تطبيق أصلي بقشرة Capacitor ومحركات Kotlin | مشغّل Media3؛ تورنت أصلي عبر libtorrent للأجهزة والمعماريات المدعومة في البناء. |
| **Windows x64** | تطبيق Electron بواجهة VANTARA | مشغّل mpv ومحرك rqbit محلي للتورنت. |
| **الويب / PWA** | واجهة قابلة للتثبيت من المتصفح | تشغيل بحسب قدرات المتصفح والمصادر المتوافقة؛ **لا يُشغِّل تورنت BitTorrent التقليدي مباشرة داخل المتصفح**. |

الميزات ليست متطابقة بنسبة 100% بين المنصات. مرجع قدرات الواجهة التنفيذي هو [`apps/web/lib/release.js`](apps/web/lib/release.js) و[`apps/web/lib/capabilities.js`](apps/web/lib/capabilities.js). وجود القدرة في القائمة لا يثبت نجاح كل سيناريو تشغيل حي.

## كيف يعمل؟

```text
                         واجهة VANTARA المشتركة
                                apps/web
                    ┌───────────┼────────────┐
                    │           │            │
                 Android      Windows      المتصفح
                 Kotlin       Electron     PWA
                 Media3       mpv           Web APIs
                 libtorrent   rqbit         مصادر ويب
                    └───────────┼────────────┘
                                │
                  الحسابات والمزامنة والخدمات
                    Cloudflare Worker + D1
```

- **المحتوى:** لكل منصة موصلات ومصادر مناسبة؛ محركات المصدر والتورنت ليست خدمة مركزية واحدة.
- **البيانات الاجتماعية والمزامنة:** `services/sync-worker` وCloudflare D1 ضمن العقود المعمول بها.
- **الويب:** `services/web-fetcher` يستخدم لجلب الموارد المسموح بها بحسب ضوابطه.
- **المحتوى المستضاف ذاتيًا:** `apps/api` و`packages/*` و`infra/` تمثل مكدسًا منفصلًا؛ لا تفترض أن كل تجربة تشغيل حديثة تعتمد على جهاز منزلي.
- **الترجمة:** توجد أعمال وتقنيات ترجمة قيد التطوير والقياس؛ لا تُعد جميع مسارات الترجمة جاهزة أو متاحة على كل منصة.

للتفصيل: [معمارية المشروع](docs/ARCHITECTURE.md) · [حالة الميزات والأدلة](docs/FEATURE_STATUS.md).

## الوصول والإصدارات

- [الإصدارات المنشورة على GitHub](https://github.com/Meshal515/VANTARA/releases): قد تحتوي على APK وحزمة Windows وتحديثات الويب حسب نجاح بناء كل منصة.
- الحصول على ملف تثبيت **لا ينشئ حسابًا أو دعوة** ولا يتيح الوصول تلقائيًا إلى بيانات مجموعة التجربة.
- بناء Windows المنشور حاليًا موجّه إلى **x64**. دعم Android **32 بت** قيد الدراسة وليس وعدًا بتوفّره.
- يختلف تشغيل المصادر وحقوق استخدامها وسياسات الوصول بحسب الجهة التي توفّر المحتوى؛ المشروع لا يرفق مكتبة تجارية من الأفلام أو الأنمي.

## للمطورين

يتطلب مستودع JavaScript/TypeScript ‏**Node.js 22 أو أحدث** و**pnpm 10.33.0**. الاختبارات والبناء الأصلي لكل منصة له متطلبات إضافية.

```bash
pnpm install
pnpm test:web
pnpm test:safety
pnpm typecheck
pnpm lint
```

- [فهرس الوثائق](docs/README.md): ما يُقرأ أولًا، وما هو مرجع تقني، وما هو تاريخي.
- [حالة المشروع](docs/FEATURE_STATUS.md): الفروق بين ميزة موجودة في الكود وميزة متحقَّق منها على جهاز.

## ملاحظات قبل المشاركة أو المساهمة

- المشروع **ليس مفتوح التسجيل للعامة حاليًا**. البلاغات التقنية مرحّب بها، لكن لا يمكن ضمان دعم كل جهاز أو مصدر.
- لا تنشر مفاتيح API أو رموز الدخول أو بيانات الأصدقاء أو روابط المصادر الشخصية داخل البلاغات أو السجلات.
- **الاطلاع العلني على الكود ليس ترخيصًا مفتوح المصدر بحد ذاته.** لم يُضَف ترخيص إعادة استخدام إلى جذر المستودع حتى الآن؛ أي قرار بإصدار ترخيص لاحق يحتاج تحديد شروطه ومراجعة تراخيص التبعيات.
- التغييرات الكبيرة تُراجع على فرع مستقل؛ لا دمج أو نشر إنتاجي دون اعتماد صريح.

---

**الفكرة الأساسية:** VANTARA ليس موقعًا عامًا للتواصل؛ هو تطبيق محتوى يجعل تجربة المتابعة والقراءة والمشاهدة مع أصحابك في مكان واحد.
