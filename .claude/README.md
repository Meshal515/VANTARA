# VANTARA — Claude Agents & Skills

هذا القسم مخصص لوكلاء التطوير (Claude Code)، **وليس ميزة Cloud Agents داخل تطبيق VANTARA**.

## المسارات
- `.claude/agents/`: 10 وكلاء تخصصيين جاهزين للاستدعاء في بيئات تدعم Claude Code subagents، كل وكيل ملف Markdown بواجهة YAML.
- `.claude/skills/`: **18 مهارة أصلية لفانتارا + 328 ملف استدعاء لمهارات خارجية**، دون حذف المهارات الأصلية.
- `.claude/vendor/sources/`: نسخ الملفات الأصلية (SKILL.md والمراجع والسكربتات والبيانات المساندة) من 20 مستودعًا، مع التراخيص والإشعارات.
- `.claude/catalog/agent-skills-2026-11-07.csv`: فهرس البحث الأصلي بـ**142 بندًا**. عدد المهارات المثبّتة الآن 328 لأنه يشمل حزمًا كاملة، لا البنود المختارة فقط.
- `.claude/vendor/installation-report.json`: تقرير كل مهارة مثبتة، مرجع المصدر والترخيص وأربع ملفات مساندة مستثناة لاحتوائها نصوصًا تشبه الأسرار.
- `.claude/catalog/agent-skills-guide-2026-11-07.md`: الدليل العربي بالمصادر وأولويات الاستخدام.

## استخدام مختصر
1. اختر الوكيل الموافق للمهمة (UI، motion، extensions، debugging، Android، Media3، browser، security، release، manga/subtitles).
2. اعمل انطلاقًا من `CLAUDE.md` والمهارة المحلية ذات الصلة، واقرأ الكود الحالي قبل أي تعديل.
3. المهارات الخارجية المرخصة MIT/Apache 2.0 موجودة الآن محليًا؛ ابدأ من ملف الاستدعاء `.claude/skills/ext-*/SKILL.md` ثم اقرأ المصدر الأصلي داخل `.claude/vendor/sources/`. لا تُنفّذ سكربتات أو تنزيلات خارجية أو telemetry دون تدقيق وإذن.
4. **ملفات المهارات ليست تثبيتًا تلقائيًا لبرامج CLI** مثل Playwright وgstack وagent-browser؛ تشغيل أدواتها يتطلب إعدادًا منفصلًا. ولم تُنفّذ أي سكربتات خارجية أثناء الاستيراد.
5. اجعل `vantara-root-cause-debugging` قائد التشخيص الواحد؛ لا تجمع تعليمات debugging متعارضة.
6. لا تغيّر كود التطبيق أو CI أو الإعدادات عند مجرد تحديث المهارات.

## Debug وStable
- GitHub workflow `android-debug.yml`: ينتج Debug من دفعات فروع العمل.
- GitHub workflow `android-stable.yml`: ينتج Stable من `main` عند نجاح VANTARA CI.
- ملفات Claude مشتركة على `main`؛ تتاح إلى Debug وStable عند البناء من commit يحتويها، **ولا تنتقل إلى فروع قديمة تلقائيًا**.
- هذه ملفات تعليمات تطوير، وليست حزمة APK أو إضافات مدمجة في التطبيق. لا تتطلب إعداد مفاتيح API.
- دفع commit إلى main قد يشغّل CI وسير Stable حسب إعداد GitHub الحالي؛ لا يعتبر ذلك اختبارًا لعمل المهارات داخل Claude Code.

## حماية المشروع
- صون ملكية البيانات المحلية، سلامة المحركات، وعدم نشر الأسرار أو نسخ كود خارجي بترخيص غير ملائم.
- التزام `CLAUDE.md` الأساسي، وإثبات التنفيذ والاختبار وعدم الدمج/النشر إلا بإذن المالك.
- الفهرس لقطة بتاريخ 2026-11-07. مصادر الاستيراد مثبتة على commit SHA معروف؛ MIT وApache 2.0، مع استبعاد مصادر بلا ترخيص صريح أو ذات CC-BY-SA.
- تم استبعاد أربعة ملفات مساندة لتطابق محتواها مع كواشف أنماط أسرار الاعتماد في CI؛ هذا لا يعني أنها أسرار حقيقية. راجع تقرير التثبيت عند الحاجة.
