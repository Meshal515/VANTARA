# VANTARA — Claude Agents & Skills

هذا القسم مخصص لوكلاء التطوير (Claude Code)، **وليس ميزة Cloud Agents داخل تطبيق VANTARA**.

## المسارات
- `.claude/agents/`: 10 وكلاء تخصصيين جاهزين للاستدعاء في بيئات تدعم Claude Code subagents، كل وكيل ملف Markdown بواجهة YAML.
- `.claude/skills/`: 18 مهارة مشروع محلية، منها **مهارتان أصليتان موجودتان مسبقًا وتم الإبقاء عليهما دون تعديل**.
- `.claude/catalog/agent-skills-2026-11-07.csv`: **142** بندًا منتقى من GitHub تشمل مهارات وأوامر فرعية وأدوات؛ **الفهرس ليس 142 مهارة مثبّتة**.
- `.claude/catalog/agent-skills-guide-2026-11-07.md`: الدليل العربي بالمصادر وأولويات الاستخدام.

## استخدام مختصر
1. اختر الوكيل الموافق للمهمة (UI، motion، extensions، debugging، Android، Media3، browser، security، release، manga/subtitles).
2. اعمل انطلاقًا من `CLAUDE.md` والمهارة المحلية ذات الصلة، واقرأ الكود الحالي قبل أي تعديل.
3. عند الحاجة إلى مصدر خارجي من الفهرس: افحص README وSKILL.md والترخيص والإصدار والأذونات، وثبّته **يدويًا بإذن صريح** وفق أداة الوكيل. لا تحوّل فهرس GitHub إلى تنفيذ تلقائي لكود طرف ثالث.
4. اجعل `vantara-root-cause-debugging` قائد التشخيص الواحد؛ لا تجمع تعليمات debugging متعارضة.
5. لا تغيّر كود التطبيق أو CI أو الإعدادات عند مجرد تحديث المهارات.

## Debug وStable
- GitHub workflow `android-debug.yml`: ينتج Debug من دفعات فروع العمل.
- GitHub workflow `android-stable.yml`: ينتج Stable من `main` عند نجاح VANTARA CI.
- ملفات Claude مشتركة على `main`؛ تتاح إلى Debug وStable عند البناء من commit يحتويها، **ولا تنتقل إلى فروع قديمة تلقائيًا**.
- هذه ملفات تعليمات تطوير، وليست حزمة APK أو إضافات مدمجة في التطبيق. لا تتطلب إعداد مفاتيح API.
- دفع commit إلى main قد يشغّل CI وسير Stable حسب إعداد GitHub الحالي؛ لا يعتبر ذلك اختبارًا لعمل المهارات داخل Claude Code.

## حماية المشروع
- صون ملكية البيانات المحلية، سلامة المحركات، وعدم نشر الأسرار أو نسخ كود خارجي بترخيص غير ملائم.
- التزام `CLAUDE.md` الأساسي، وإثبات التنفيذ والاختبار وعدم الدمج/النشر إلا بإذن المالك.
- الفهرس لقطة بتاريخ 2026-11-07؛ يلزم مراجعة تراخيص وإصدارات المصادر قبل إدخال ملفاتها.
